# Ball Battles

Простенькая браузерная игра, основанная на механике битвы двух и более шаров с разными видами оружия.

Создано на основе роликов с аккаунта [@3d_animation_1610](https://www.instagram.com/3d_animation_1610/).

## Запуск

```powershell
npm install
npm start
```

После запуска откройте `http://127.0.0.1:4173`.

## Смена IP адреса и порта

При желании, мы можете изменить дефолтные IP и порт, создав файл .env со следующим содержимым:

```text
HOST=[IP-адрес]
PORT=[Порт сервера]
```

Далее запустите сервер:

```bash
npm run serve
```

## Механика

- В начале игры выбираются от двух до четырёх шаров;
- Шары движутся и упруго сталкиваются внутри круглой арены;
- На арене случайно появляются автомат, Uzi, дробовик, пистолет, нож и щит;
- Оружие автоматически наводится на соперника;
- Попадания снимают здоровье, а щит блокирует несколько атак;
- Бой можно поставить на паузу или перезапустить.
